使い方のポイント（3ステップ）

実演①：市場調査 → 出典付き提案書スライド 実演②：社内データ → 3資料同時生成＆スキル化

実演 ① 市場調査からの提案書作成

Step 1：Gemini Notebook（旧NotebookLM）用

出典付き「要点メモ」作成プロンプト

自社資料をアップロードし、ディープリサーチで市場データを集めた後に実行します。Claudeに渡すための骨組みと出典テキストを一気に出力します。

アップロードした自社資料と、ディープリサーチで収集した最新トレンド・市場データを統合し、【社内決裁用の「新規獲得キャンペーン企画提案書」】に使う要点メモを作成してください。

以下の5セクションで整理してください。
1. 【対象業界（例：食品・飲料D2C）】における最新の市場・集客トレンド
2. 従来の施策の課題と、今回の施策が注目される背景
3. 自社サービス【自社ブランド・商品名】の現状と狙うべき施策案（【予算上限・社内体制などの制約条件】で回る現実的な案）
4. 具体的な企画案（施策内容・顧客への訴求ポイント・初回特典など）
5. 想定スケジュールとKPI（【目標数値（例：新規獲得150件）】の達成シミュレーション）

【重要ルール】
・すべての市場データ・数値・事例には、必ず「（出典：機関名・年・資料名）」の形式で出典元をテキストで明記してください。
・アップロードした自社資料に記載のない数値は推測で作らないでください。
実務のコツ：Gemini Notebookの引用リンクはコピーすると消えるため、必ずテキストとして出典を出力させてからClaudeへ渡します。
Step 2：Claude / Claude Code 用

編集可能なPowerPointスライド生成プロンプト

Step 1で出力した要点メモをコピー（またはテキストファイルとして添付）し、Claudeへ渡して実行します。

添付の要点メモをもとに、【部長決裁用の企画提案書】のスライドを全【10】枚、編集可能なPowerPoint（.pptx）形式で作成してください。

【作成ルール】
・ビジネスでそのまま使える、【清潔感のある落ち着いた色合い（例：ブラウンと白を基調）】の見やすいデザインにすること。
・1スライド1メッセージとし、文字を詰め込みすぎず箇条書きや表を活用すること。
・要点メモ内の数字は一切変更・推測しないこと。
・市場データや数値を記載したスライドの下部には、必ず要点メモの出典元を記載すること。

実演 ② 社内データからの3資料同時生成と自動化

Step 1：Gemini Notebook（旧NotebookLM）用

社内データの統合「要点メモ」作成プロンプト

実績データ・アンケート結果・会議議事録など、複数の社内資料をアップロードした状態で実行し、矛盾のない1枚の要点メモを作ります。

アップロードした【3つ】の社内資料（【実績サマリー、アンケート集計、振り返り会議議事録】）のみをもとに、報告用の「要点メモ」を作成してください。

以下の3セクションで整理し、すべての数値や決定事項の末尾に、どの資料から引用したかを「（参照：資料名）」と明記してください。
1. 全体実績サマリー（費用、獲得数、目標達成率、主要KPI、内訳）
2. 顧客・現場の声（満足度、評価された点トップ3、改善要望トップ3）
3. 次回以降の改善アクション・担当者・期限

【重要ルール】
・アップロードした資料に記載のない数字の推測・補完は一切行わないでください。
Step 2：Claude / Claude Code 用

相手別「3資料の同時生成」プロンプト

Step 1で作成した要点メモを添付し、提出先の異なる3つの成果物を一括生成します。

添付の要点メモのみをもとに、以下の3種類の資料を同時に作成してください。要点メモに記載のない数字の推測や変更は厳禁です。

1. 【部長・経営層向け】振り返りサマリースライド（PowerPoint形式・5枚。結論と重要数値のみシンプルに整理）
2. 【社内チーム向け】改善アクション詳細レポート（Word形式。媒体・項目別の振り返り、顧客の声、担当者・期限を表形式で整理）
3. 【顧客・関係者向け】お礼と今後の改善スケジュールのお知らせメール文面（温かく丁寧なトーン）
Step 3：Claude / Claude Code 用（自動化）

翌月以降も再現できる「スキル登録」プロンプト

Step 2の出力がうまくいった直後に続けて送信することで、同じフォーマット・手順をスキルとして保存します。

今行った「要点メモから、経営層向けスライド・チーム向け詳細レポート・お礼メールの3点セットを作成する手順とフォーマット」を、次回以降の振り返りでも再現できるスキル（スキル名：【campaign_review_3set】）として登録してください。
次回以降の運用：Gemini Notebookで今月分の要点メモを出し、Claudeに渡して登録したスキルを呼び出すだけで完了します。
